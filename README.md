# error-correction-codes-modeling

This program encodes binary messages using different methods for detecting and correcting errors that may occur during data transmission.

Currently, the implemented methods include the parity bit, triple redundancy, and Hamming code.

The program also includes a test that analyzes the results and evaluates the effectiveness of each method. This makes it possible to compare how different encoding methods perform and determine how suitable they are for a given data transmission scenario.

Methods are implemented in Python.
